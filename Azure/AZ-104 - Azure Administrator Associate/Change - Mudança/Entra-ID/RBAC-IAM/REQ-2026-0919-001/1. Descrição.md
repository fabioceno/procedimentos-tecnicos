# CHAMADO — Restrição de Convites para Usuários Externos no Microsoft Entra ID.

* Número do chamado: ** REQ-2026-0919-001.
* Categoria: Cloud / Microsoft Entra ID.
* Subcategoria: Governança e Identidade.
* Prioridade: Média.
* Ambiente: Produção.
* Status: Aberto.
* Solicitante: Equipe de Segurança da Informação.
* Responsável: Equipe de Cloud / Identidade

## 1. Descrição da Solicitação.

A equipe de Segurança da Informação solicita a implementação de uma política de controle para restringir o envio de convites para usuários externos (Guest) no Microsoft Entra ID.

Atualmente, usuários com permissões administrativas ou operacionais podem realizar convites de usuários externos para o Tenant, o que pode gerar riscos relacionados à governança de identidades, acesso indevido a recursos corporativos e falta de rastreabilidade sobre a criação de usuários convidados.

Solicita-se que o envio de convites para usuários externos seja bloqueado para usuários comuns, permitindo essa ação somente para usuários previamente autorizados, classificados internamente como:

* Nível Senior.
* Nível Gerente.

A alteração deverá ser realizada considerando os recursos nativos de governança e colaboração externa disponíveis no Microsoft Entra ID.

## 2. Objetivo.

Implementar um controle centralizado para garantir que a criação/convite de usuários externos seja realizada somente por usuários autorizados.

O objetivo é:

* Reduzir o risco de criação indiscriminada de contas Guest;
* Melhorar a governança de identidades externas;
* Restringir a capacidade de convite a usuários autorizados;
* Aumentar a rastreabilidade das solicitações de acesso externo;
* Atender às políticas internas de Segurança da Informação;
* Aplicar o princípio do menor privilégio.

## 3. Regra de Negócio.

A configuração deverá seguir a seguinte regra:

Perfil do usuário	Enviar convite para usuário externo.

* Usuário comum:	❌ Bloqueado.
* Nível Master:	✅ Permitido.
* Nível Gerente:	✅ Permitido.
* Administrador autorizado:	✅ Conforme política interna.

A autorização deverá ser aplicada de forma controlada, evitando que usuários comuns consigam contornar a restrição por meio de outras permissões administrativas.
